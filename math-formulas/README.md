# Математика в формулах

Веб‑приложение с описанием плоских геометрических фигур и примерами расчётов.

## Версии
- v1.0: базовый релиз (3 фигуры, 3 примера).
- v1.1: добавлены треугольник и трапеция (5 фигур, 5 примеров).

## Инструкция запуска
1. Клонировать репозиторий.
2. Открыть `index.html` или `examples.html` в браузере.

## Источники
- Формулы: школьные учебники по геометрии.
- Изображения: бесплатные стоки (указать ссылки).
